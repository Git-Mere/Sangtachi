# 살아 있는 문서끼리 어긋난 곳을 맞춘다

## 왜 했나

Phase 9 를 닫은 뒤 살아 있는 문서 전체를 서로 대조했다. 기록 문서(`audit-history/`, `commit_history/`, `decisions/`, `issue_history/`, `first_design.md`, 날짜별 실측 기록, `my-notes/`)는 뺐다. 중간 12건, 낮음 약 30건이 나왔다. 정할 것은 저장소 소유자가 정했고 나머지는 단일 출처 쪽으로 맞췄다.
