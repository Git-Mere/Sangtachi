# 루트 README 를 쓴다

## 왜 했나

`plan.md` 문서 부채에 루트 `README.md` 의 자리 표시 문구(개요, 스크린샷)가 남아 있었다. Phase 1~9 가 끝나 소유자가 다음 작업으로 정했다. 레포를 처음 보는 사람(채용 담당, 다른 학생)이 무엇을 하는 프로젝트이고 어떤 결과가 나왔는지 한 화면에서 알게 하는 것이 목적이다.

## 바꾼 것

| 자리 | 무엇 |
|------|------|
| `README.md` | 영어로 다시 썼다. 한 줄 소개, 문서 링크 줄, Highlights, About, Features, How It Works(Mermaid 그림과 5단계), Results, Built With, Getting Started, Telemetry, Repository Layout, What I Learned, License |
| `README.ko.md` | 새 파일. 같은 내용의 한국어판. 두 파일 머리에 서로를 가리키는 언어 링크를 둔다 |
| `plan.md` | 문서 부채의 루트 `README.md` 자리 표시 문구 행을 GUI 스크린샷과 배포물 링크 행으로 바꿨다 |

원래 README 의 빌드, 시험, 실행, 환경 변수, 텔레메트리, 레포 구조 내용은 빠짐없이 옮겼다. 영어판은 번역했고 한국어판은 원문을 두되, 리뷰에서 틀렸다고 나온 실행, 빌드 경로, 시험, 텔레메트리 문구는 두 판을 같이 고쳤다. 새로 더한 것은 관리자 권한 요구(`windows-prereq.md` 1절 링크), GUI 배포 폴더를 만드는 `package-gui.ps1` 명령, Minecraft 로 접속하는 세 단계(`windows-prereq.md` 5절과 11절 내용)다.

## 중요한 결정

- **수치의 출처는 `experiments.md` 다.** README 의 RTT, 성공률, 손실, Minecraft 수치는 `experiments.md` 3.2, 3.4, 6.2, 6.3, 6.5 를 요약한 것이고 Results 절에서 그 문서로 링크한다. README 는 `docs/` 의 살아 있는 문서가 아니라 소개 문서라서 요약을 두었다. 실측이 바뀌면 README 도 같이 고친다
- **시험 개수는 "690+", "260+" 로만 쓴다.** Catch2 는 Phase 9 닫기 기록(`2026-11-23/03`)의 실행 결과 단위 시험 693/693 을, pytest 는 2026-11-23 기준 `control-server/`·`telemetry-server/` 소스의 `def test_` 선언 264개를 내림했다
- **스크린샷 절은 두지 않는다.** GUI 스크린샷과 배포물 다운로드 링크는 아직 없어 `plan.md` 문서 부채로 남겼다. 그 대신 Phase 9 그래프 둘(`docs/assets/phase9/`)을 Results 에 넣었다
- 시간 값(keepalive 15초, `PING` 5초, 유휴 50초)은 `protocol.md` 11장 타이머, 방 코드 6자는 `control_plane.md` 의 방 코드 정의를 따른다
