# Tests for a Person to Run

## Why

Every test that can run on one machine today is now automatic. What a person can run now needs a second machine. Capture C6-C9 need new fake-peer modes and are not in this list (`plan.md`, waiting). The repository owner
asked for those as one concise list, with overlapping items merged into one run.

four system DLLs (`WS2_32`, `bcrypt`, `IPHLPAPI`, `KERNEL32`). The build command is in that README; the repository's build
settings were not changed.
