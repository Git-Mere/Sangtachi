## 무중계 스타 후속

[ADR 0006](decisions/0006-무중계-스타-토폴로지.md)이 한 방 5인과 무중계 스타, 역할 일반화를
정했다. 그 결정이 살아 있는 문서와 코드에 아직 반영되지 않았다.

**비용은 코드가 아니라 문서다.** 세션 상태를 지는 모듈 6개가 아직 레포에 없으므로
([`architecture.md`](architecture.md) 3.1 모듈 표), 코드 쪽은 고치는 것이 아니라 처음부터
목록으로 쓰는 것이다.

| 대상 | 건수 | 시점 |
|------|:----:|------|
| [`protocol.md`](protocol.md) 범위 라벨 | 23 | 먼저. 기계적이다 |
| 신규 서술 (랑데부, 준비 완료, 제어 응답 라우팅) | 3 | Phase 3 착수 전 |
| 나머지 문서 (신규 9 + `architecture.md`·[`concurrency.md`](concurrency.md) 기존 16) | 25 | Phase 4 착수 전 |
| 코드 | 9 | Phase 4 구현 중. **`TimerSet` 2건은 예외로 먼저** |
| 시험 | 4 | 코드와 같이 |

`TimerSet` 을 먼저 고치는 이유는 세션 키도 제거 함수도 없어서다. `HELLO` 재전송과 keepalive
타이머를 세션 수만큼 올리면 이름이 충돌한다.

### 아직 정하지 않은 것

ADR 0006 의 "이 ADR 이 정하지 않는 것" 과 같은 목록이다. 의존 순서로 적는다.

| 순서 | 질문 | 걸리는 문서 |
|:--:|------|-------------|
| 1 | 호스트가 사라졌을 때 플레이어 프로세스가 무엇을 하는가. 종료인가 대기인가 | [`concurrency.md`](concurrency.md) 7장 |
| 2 | 준비 완료와 `punch_delay_ms` 를 방 단위에서 쌍 단위로 옮기는가 | [`control_plane.md`](control_plane.md) 4.4, [`protocol.md`](protocol.md) 10.2 |
| 3 | 라우팅 표의 모양과 송신 검사 순서 | [`protocol.md`](protocol.md) 8.5 |
| 4 | 플레이어가 방 명부와 연결 상태를 어디서 받는가 | [`protocol.md`](protocol.md) 5장, [`control_plane.md`](control_plane.md) 4.5 |
| 5 | 나간 피어의 가상 IP 자리를 회수하는가 | [`control_plane.md`](control_plane.md) 2.5 |

**1번의 터널 쪽 답은 이미 나와 있다.** 스타에서는 모든 터널의 한쪽 끝이 호스트이므로 호스트가
사라지면 터널이 전부 끊긴다. ADR 0006 결정 4 다. 남은 것은 그때 플레이어 프로세스가 무엇을
하는가와 제어 평면의 방 항목이 어떻게 되는가다.

**4번은 GUI 범위 결정과 묶인다.** 아래 절이 그것을 적는다.

## GUI 범위 결정 대기

저장소 소유자가 최종 제품 형태에 GUI 를 포함한다고 말했다. 아직 결정으로 기록하지 않았다.

지금 문서는 반대로 적혀 있다. [`spec.md`](spec.md) 가 "고급 GUI" 를 제외에, "간단한 GUI" 를
스트레치 목표에 두고, 우선순위 등급 P4 는 범위를 넘을 때 가장 먼저 잘리는 등급이다.

**GUI 결정의 대부분은 토폴로지와 무관하다.** 프로세스 모델, 스레드, 입출력 경로가 그렇다.
그래서 따로 정해도 된다. **다만 네 자리는 위 "무중계 스타 후속" 과 같은 문장을 건드린다.**

| 겹치는 자리 | 무엇이 겹치나 |
|-------------|---------------|
| [`protocol.md`](protocol.md) 5장 | 방 명부를 나르는 새 터널 메시지가 필요한지. 위 미결 4번과 같은 질문이다 |
| [`architecture.md`](architecture.md) 3.5 | 재참가 증명을 표준 출력에 내고 사람이 복사하는 규칙 |
| [`concurrency.md`](concurrency.md) 7장 | 종료를 콘솔 핸들러가 신호하는 규칙 |
| [`architecture.md`](architecture.md) 8장과 9장 | 실패 코드를 사람에게 어떻게 보이는가 |

**이 넷은 문서 수정에 들어가기 전에 정하는 것이 싸다.** 나중에 정하면 같은 문서를 두 번 연다.
