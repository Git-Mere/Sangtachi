# 0023. 3차 H·I 착수 전 결정

- 상태: 채택
- 날짜: 2026-10-12
- 관련: [`../roadmap.md`](../roadmap.md) Phase 4, [`../protocol.md`](../protocol.md) 5.7·11장, [`../concurrency.md`](../concurrency.md) 3장, [`../architecture.md`](../architecture.md) 9장

## 맥락

Phase 4 3차의 H(라우팅 표, `DATA` 송신, `send` 명령, 에코 응답기)와 I(`ROSTER` 송신과 시점)를 시작하기 전에 문서가
정하지 않은 자리가 일곱 있었다. 저장소 소유자가 각 자리의 선택지 가운데 하나를 골랐다. M-5 비교와 명부 변화의 판정은
추천 하나만 제시했고 소유자가 받아들였다. 그 둘의 대안은 이 기록을 쓰면서 적은 것이다.

## 결정

| 자리 | 고른 것 |
|------|---------|
| 페이로드 훅이 제품 빌드에 남지 않게 | 훅 칸은 core 에 두고 제품 빌드는 비워 둔다. 시험 전용 코드(송신 측 `data.tx`, 칸에 붙는 `data.rx` 와 에코 응답기)는 시험 빌드 CMake 옵션 안에만 컴파일한다 |
| `send` 의 목적지 | `send <n> [size] [to]`. `to` 는 목적지 가상 IP 다. `CONNECTED` 세션이 하나일 때만 생략할 수 있다 |
| M-5 비교를 두 프로세스 사이에서 하는 법 | 시험 빌드 로그 `data.tx`, `data.rx` 가 비교 지점의 `len` 과 `sha256` 을 싣고 스크립트가 대조한다 |
| `ROSTER` `generation` 의 첫 값 | 방을 세울 때 0. 호스트에 하나다 |
| `CONNECTED` 진입 때 겹치는 즉시 송신 | 한 번이다. 11장 주기의 진입 송신과 5.7 명부 변경의 즉시 송신이 같은 송신이다 |
| 명부가 바뀐 것의 판정 | 실을 내용(멤버, 이름, 비트 0)이 직전과 다를 때 |
| 플레이어가 받은 명부를 보이는 곳 | 받아들인 명부마다 `roster` 로그 줄 하나 |

I 는 멤버 목록을 입력으로 받는 데까지 만들고, 그 입력을 `host_report` 응답에 잇는 일은 4차 J 가 한다.

## 대안

**훅.** 지금처럼 `main.cpp` 가 비워 두는 것만으로 지키는 안을 버렸다. 실수로 훅을 걸어도 컴파일이 막지 못한다. 칸 자체를
시험 빌드로 가르는 안도 버렸다. 그 칸은 Phase 6 에서 Wintun 주입 경로로 이어진다.

**`send` 목적지.** `CONNECTED` 세션 전부로 보내는 안과 첫 세션으로 보내는 안을 버렸다. 전부로 보내면 쌍 하나를 보는 시험이
다른 쌍의 송신과 섞이고, 첫 세션은 어느 것인지 명령에서 보이지 않는다.

**M-5 비교.** 바이트열 전체를 16진으로 로그에 싣는 안을 버렸다. 1452바이트 패킷 1000개면 로그가 수 MB 가 된다. 해시는
비교 지점의 바이트열 전체로 계산하므로 일치 판정의 힘은 같다.

**`generation` 첫 값.** 1 로 시작하는 안을 버렸다. 수신 쪽은 첫 값을 무엇이든 받으므로 동작 차이는 없고, 5.7 의 "수신자는
0 부터 받아들인다" 와 맞는 쪽을 골랐다.

**겹치는 송신.** 두 번 보내는 안을 버렸다. 같은 내용을 같은 순간에 두 번 보낼 이유가 없다.

**명부 표시.** 콘솔 명령 `members` 를 더하는 안과 Phase 8 GUI 까지 아무것도 하지 않는 안을 버렸다. 4차 K 의 검증 스크립트가
명부의 도착을 볼 수단이 필요하고, 로그 줄 하나가 가장 작다.

## 결과

**얻는 것.**

- 제품 바이너리에 시험 코드가 들어가지 않는다
- 호스트에서도 `send` 가 어느 상대로 가는지 명령에 드러난다
- 두 프로세스의 왕복 일치를 로그만으로 판정할 수 있다

**치르는 것.**

- `send` 의 계약이 `send <n> [size]` 에서 바뀌었다. 인자가 하나 는다
- 로그의 고정 이벤트가 셋 늘었다. 그중 둘은 시험 빌드에만 있다
- 재협상이 잦은 세션에서는 비트 0 이 바뀔 때마다 `generation` 이 오르고 즉시 송신이 따라온다
