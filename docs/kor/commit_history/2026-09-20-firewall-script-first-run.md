# 2026-09-20 방화벽 시험 스크립트 첫 실행

## 변경

`unsolicited-firewall-test.ps1` 을 Windows 에서 처음 실행했다. **파싱조차 되지 않았다.**

- `tools/nat-probe/unsolicited-firewall-test.ps1` 에 UTF-8 BOM 추가
- `tools/nat-probe/test_natprobe.py` 에 회귀 시험 5건 추가 (146 -> **Windows 151**, Linux 149).
  마지막 2건은 Windows 전용이다. 하나는 `powershell` 을 찾고, 다른 하나가 실제 파서를 부른다.
  `NEXT-ON-WINDOWS.md` 가 적어 둔 `145` 는 낡은 값이었다. 실제 시작값은 146 이다
- `tools/nat-probe/README.md` 12장: 실행 상태 갱신, 시행마다 손으로 두 번 입력한다는 사실 명시
- `tools/nat-probe/NEXT-ON-WINDOWS.md` 갱신

## blocker — 스크립트가 실행될 수 없었다

Windows PowerShell 5.1 은 BOM 없는 `.ps1` 을 **ANSI 코드페이지로 읽는다.** 한국어 Windows
에서는 CP949 다. UTF-8 로 저장된 한글 주석과 문자열이 전부 깨지고, 깨진 바이트가 따옴표와
중괄호를 갈라 구문 오류 10건이 난다.

```
Unexpected token '??젣媛' in expression or statement.
Missing closing '}' in statement block or type definition.
The string is missing the terminator: ".
```

첫 줄이 실행되기 전에 파서가 파일 전체를 거부한다. **`-Trials` 검증도, 관리자 확인도,
뮤텍스도 돌지 않는다.** PowerShell 7 은 BOM 없는 UTF-8 을 기본으로 읽으므로 이 문제가 없다.
그래서 `pwsh` 로만 시험했다면 끝까지 못 봤을 것이다. 이 레포의 대상은 Windows 10/11 기본
셸인 5.1 이다.

BOM 3바이트를 붙이니 파싱이 통과하고 한글도 정상 출력된다. PowerShell 7 도 BOM 을 읽는다.

**예측이 맞았다.** 직전 커밋이 남긴 문장 그대로다.

> 이 커밋의 blocker 6건 중 3건이 "정상 상태에서 실행 불가" 였고, 전부 정적 검토로만 잡았다.
> 실행했으면 첫 줄에서 나왔을 것들이다.

17라운드의 정적 리뷰가 놓쳤다. 리뷰어도 나도 파일 내용만 읽었고, 아무도 **파일을 무엇이
어떤 인코딩으로 읽는지** 보지 않았다. 실행 1회가 첫 줄에서 잡았다.

## 고치지 않은 것

**시행마다 상대 엔드포인트와 Enter 를 손으로 입력한다.** 기본 8회면 16번이다. 스크립트가
`natprobe` 에 `--peer` 를 넘기면 없앨 수 있지만 **넘기지 않는다.** 직전 커밋이 상대 주소를
명령줄·`Read-Host`·트랜스크립트에서 없애려고 다섯 라운드를 썼다. `--peer` 는 그 주소를
프로세스 목록과 PowerShell 기록에 그대로 되돌려 놓는다. 불편이 그 결정의 값이다.
README 12.1 에 적어 실측 전에 알게 했다.

**첫 지적이 규칙 7의 재발이다.** BOM 존재를 보는 것은 원인 하나를 보는 진단이고, 판정은
"파싱되는가" 다. 진단을 판정 자리에 놓았다. 실제 파서를 부르도록 고쳤고, BOM 을 지우면
그 시험이 실패하는 것을 확인했다.

**7라운드 기각 사유.** 링크는 맞다. 파일이 `tools/nat-probe/` 에 있으므로 `../../` 는
레포 루트이고 `../../docs/kor/...` 는 `docs/kor/...` 다. 이번 변경에 닿는 네 문서의 상대
링크 13개를 전부 해석해 실재 파일인지 확인했고 끊긴 것은 없었다. 리뷰어도 "검증되면" 이라는
조건을 달았다.

**3라운드 기각 사유.** 어긋나지 않는다. **단위가 둘이고 둘 다 맞다.** 옵션 `-Trials` 는 **쌍 수**
이고 기본값은 4다. 산문의 "기본 8회" 는 **시행 수**다. 4쌍 = 8시행이므로 같은 설정을 가리킨다.
리뷰어는 이 둘을 같은 단위로 읽고 4와 8이 어긋난다고 보았다. 헷갈리기 쉬운 것은 사실이라
`NEXT-ON-WINDOWS.md` 에 "`-Trials` 는 쌍 수이고 시행은 그 두 배" 라고 이미 적어 두었다.
