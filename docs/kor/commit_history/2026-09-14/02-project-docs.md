- `CSP400_P2P_Virtual_Network_Proposal.md` -> `docs/first_design.md` 이동 및 개명

## 결정

- `plan.md`는 건드리지 않았다. `roadmap.md`가 Phase 단위 큰 계획,
  `plan.md`가 현재 작업 단위 체크리스트로 역할을 나눈다.
- 터널 헤더 정의를 Phase 5에서 Phase 4로 옮겼다. 홀펀칭이 `HELLO`/`KEEPALIVE`/
  `PING`/`PONG`을 구분해야 하므로 `type` 필드가 Phase 4에서 이미 필요하다.
  임시 포맷을 쓰면 Phase 4 코드를 버리게 된다. Phase 4는 헤더 기본형,
  Phase 5는 `DATA` 타입과 견고성을 담당한다.
- 각 Phase의 산출물이 기획서에서는 그림 수준이라 통과 판정이 불가능했다.
  Phase마다 성공/실패를 가를 수 있는 검증 항목을 별도로 추가했다.
- MTU 계산(1500 기준 내부 IP 패킷 최대 1456B)을 추가했다. 기획서에는
  "handle packet size limits"만 있고 수치가 없었다. 실값은 Phase 7 실측으로 확정.
- Wintun 승인 지연을 위험 항목에 추가했다. 승인 대기 중에는 어댑터가 필요 없는
  Phase 9 측정 항목을 선행한다.
- `first_design.md`는 참고 자료이며 확정 사양이 아니다. 세 문서와 충돌할 경우
  세 문서가 우선한다.
