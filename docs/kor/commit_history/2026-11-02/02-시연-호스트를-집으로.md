# 시연 호스트를 소유자의 집 Wi-Fi 로 옮긴다

## 왜 했나

리허설 날 학교 유선 LAN 에서 Tailscale 이 막혀 다른 기기를 원격으로 다룰 수 없었고, 핫스팟을 들고 자리를 뜨자 호스트가 끊겼다. 저장소
소유자가 시연 망을 바꿨다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 호스트 G 는 소유자의 집 Wi-Fi, 소유자 A 는 학교에서 휴대폰 핫스팟, 시연 플레이어와 친구는 각자의 집 Wi-Fi. ADR 0034 의 시연 망을 뒤집는다 | [ADR 0038](../../decisions/0038-시연-호스트를-집-wi-fi-에-둔다.md) |
| 3.3 리허설이 그때의 시연 망이었다고 적었다 | `experiments.md` 3.3 |
| 새 시연 망의 리허설을 남은 일로 넣었다 | `field-test/required-test.md`, `plan.md` |
| G 를 집에 사람 없이 둔다. Minecraft 서버는 꺼 두었다. 친구가 참가하면 화이트리스트에 넣는다 | `plan.md` |

| 지적 | 처리 |
|------|------|

| [A] `required-test.md` 의 "학교 망 안의 기기끼리는 연결되지 않았다" 가 같은 유선 LAN 두 기기의 연결과 어긋난다 | 반영. 학교 유선 LAN 과 학교 Wi-Fi 의 두 기기로 좁혔다 |
