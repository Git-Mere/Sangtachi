# 사람이 돌릴 시험 목록

## 왜 했나

같은 기기에서 지금 돌릴 수 있는 시험은 다 자동이 됐다. 지금 사람이 돌릴 수 있는 것으로 남은 것은 두 번째 기기가 있어야 하는 것이다. 캡처 C6~C9 는 새 가짜 피어 모드가 있어야 해서 이 목록에 넣지 않았다(`plan.md` 대기). 저장소 소유자가 그것을 간결한
목록 하나로, 겹치는 것은 한 번의 실행으로 묶어 달라고 했다.

## 무엇을 바꿨나

| 무엇 | 자리 |
|------|------|
| 시험 넷(다른 두 집, 같은 공유기, 선택 둘)과 준비, 보낼 파일. 다른 두 집 한 번이 nat-probe 재측정, 로비 체류, Phase 3 산출물, Phase 4 의 다른 가정망 항목, 캡처 D1·D2, M-2, 기록 파일을 함께 덮는다 | `tools/field-test/README.md` |
| D1 은 A 한쪽 캡처로 판정한다(B 가 AWS 를 거치면 A 에 도착한 패킷의 출발지가 Elastic IP 다). B 의 수신은 B 의 로그로 본다. D2 는 A 만 판정한다. D3 은 로그로 판정하고 캡처는 대조용이다 | `tools/phase4-capture/README.md` |
| 다음 할 일 1번이 그 목록을 가리킨다 | `plan.md` |

친구에게 줄 실행 파일은 C 런타임을 정적으로 넣은 Release 빌드다. 의존성은 시스템 DLL 넷(`WS2_32`, `bcrypt`, `IPHLPAPI`,
`KERNEL32`)뿐인 것을 `dumpbin /dependents` 로 봤다. 빌드 명령은 그 README 에 있고 레포의 빌드 설정은 바꾸지 않았다.

## 크로스 모델 리뷰

Codex 에 항목 덮기와 판정의 정확성으로 돌렸다.

| 지적 | 처리 |
|------|------|
| warn. 매핑 수명 45초를 통과로 받으면 `간격 × 3 < 수명` 을 어긴다 | 반영. 45초보다 커야 한다 |
| warn. 가장 긴 지연 하나로는 판정 불가 결과도 통과한다. 여러 번 재어 구간이 겹쳐야 한다 | 반영. 두 번 재어 `bounded`/`at_least` 이고 구간이 겹쳐야 한다 |
| warn. 사설 주소인지만 보면 학습 주소가 상대의 로컬 후보인지 모른다 | 반영. `IP:포트` 전체를 `control.peers` 의 후보와 대조한다 |
| warn. D2 를 A 캡처만으로 하면 B 의 포트는 볼 수 없다 | 반영. D2 를 A 만의 판정으로 바꾸고 A 프로세스의 포트 소유를 모은다 |

수정 확인 리뷰는 `LGTM - no blockers` 였다.
