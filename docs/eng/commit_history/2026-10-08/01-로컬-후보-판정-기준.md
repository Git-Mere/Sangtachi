# Local Candidate Decision Criteria (ADR 0017)

## Why

One of the Phase 4 decisions to take before starting, first in "next" of `plan.md`. `protocol.md` 10.1 said
to exclude loopback, APIPA, our own Wintun, and other tunnel/VPN adapters from "active IPv4 interfaces", but
there was no decision input for "active" or "tunnel/VPN".

The pros and cons of six options (`IfType` exclusion list, name strings, gateway, `HardwareInterface`,
default route only, no filtering) and a draft case table were shown to the repository owner, who chose the
recommendation. The three related items raised alongside (scope of the own-subnet set, prefixes 31 and 32,
cut order when over the cap) were also decided as recommended.

| Question | Decision |
|------|------|
| Active | `OperStatus` `Up` and address `DadState` `Preferred` |
| Tunnel/VPN | Exclude `IfType` 24, 53, 131, 23. Anything outside the list is included. Virtual adapters with `IfType` 6 are not filtered |
| Our own Wintun | Checked separately by the recorded `InterfaceGuid` |
| Registered list | Reflexive candidates, local candidates of the default-route interface, remaining local candidates. First 8 after deduplication |
| Own-subnet set | Addresses that passed only the active stage. No loopback range; prefixes 0 to 30 only |

## Important decisions

- **It is an exclusion list.** The documentation workflow recommends allowlists for safety-relevant
  classification. This decision picks where to send, and amplification is stopped by 10.1 hygiene and
  Chapter 7 source hygiene, so it was judged not to be a safety classification. Unknown `IfType` values
  are included
- **The default route is the `0.0.0.0/0` route.** The proposal also mentioned "the best route toward the
  STUN server". With a full-tunnel VPN the ordering would lose its meaning, so `0.0.0.0/0` was chosen
  (ADR 0017 Alternative 9)
- **Which thread builds the own-subnet set and how the receive loop gets it is not decided.** That belongs
  to `concurrency.md`, so it was left as document debt in `plan.md`

## Lessons

In the English mirror, section names of other documents were translated from the Korean headings and did
not match the actual English headings, so two places were fixed (`control_plane.md` 8.4, `windows-prereq.md`
Section 3). When citing a section name in the English mirror, read the English file's heading line and copy
it. This is an observation, not promoted to a rule.

A second lens (repair check, mirror, contradictions in new text) was run on the staged diff with the repairs.

| Finding | Handling |
|------|------|
| warn. Residual-risk replies are not always bound by the budget. 9.4 exempts approved candidates and `peer_endpoint` | Accepted. The caveat is in 10.1, ADR Alternative 11, and this record |
