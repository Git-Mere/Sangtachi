# Commit Records Split into Date Folders

## Changes

- Moved 41 records from `docs/{kor,eng}/commit_history/YYYY-MM-DD-topic.md` to
  `YYYY-MM-DD/NN-topic.md`. 82 files across both trees, all with `git mv` so history follows
- `NN` is the commit-time order in which the record was added, taken from `git log --diff-filter=A`
- Fixed every reference to an old name. Relative link depth inside records (`../X` -> `../../X`)
  in 12 files, 2 sibling links between records, and `commit_history/<old name>` references in
  `CLAUDE.md` (5), `decisions/` (4), `tools/nat-probe/records/` (1), `tools/winprereq/` (1), and
  many record bodies
- One naming rule line in `CLAUDE.md` and both `commit_history/README.md`
- Two date-folder pairing tests in `tools/docgate/test_docgate.py`

## Decisions

**The folder name keeps the date already in the file name.** Record dates are not changed.

**The file name does not use `HHMM`.** For 6 records the date in the file name differs from the
actual commit date. Using the time in the name would sort those 6 in the wrong order inside the
folder. The sequence number always matches the time order.

| What | Value |
|------|-------|
| Records moved | 41 per language, in 8 folders |
| Records whose name did not match | 6. The file-name date differs from the commit date |
| References fixed | relative links in 12 files, name references in 25 files |
