# 0028. 시험용 `--peer`, `raw`, `rx.raw` 제거

- 상태: 채택
- 날짜: 2026-10-19
- 관련: [`../architecture.md`](../architecture.md) 3.5·9장, [`../concurrency.md`](../concurrency.md) 1·3장, [`../roadmap.md`](../roadmap.md) Phase 1·7

## 맥락

Phase 1 은 제어 평면도 STUN 도 없이 알려진 두 엔드포인트 사이의 송수신을 확인했다. 그 확인을 위해 세 가지를 두었다.

- 기동 인자 `--peer <IPv4>:<포트>`. 상대 주소를 직접 받는다
- 콘솔 명령 `raw <바이트 수>`. 그 주소에 터널 헤더가 없는 시험 바이트열을 하나 보낸다
- 로그 `rx.raw`. 받은 데이터그램마다, 그리고 `raw` 로 보낸 것마다 `len` 과 `sha256` 을 남긴다

문서는 셋을 시험용으로 두고 언제 지울지는 정하지 않았다. `scripts/e2e-check.ps1` 이 이것으로 Phase 1 검증을 돌았다.

Phase 7 에서 어댑터와 터널이 이어지면 실제 트래픽이 `DATA` 로 흐른다. 그러면 두 가지가 걸린다.

- `rx.raw` 는 받은 데이터그램마다 `INFO` 한 줄을 낸다. 게임 트래픽에서는 로그가 넘친다
- `--peer` 와 `raw` 는 사용자가 준 아무 주소로 세션도 인증도 없이 시험 바이트열을 보낸다. 제품 경로가 생긴 뒤에는 남길 이유가 없다

## 결정

Phase 7 의 첫 작업으로 셋을 지운다. 저장소 소유자가 정했다.

| 자리 | 고른 것 |
|------|---------|
| `--peer` | 지운다. 주면 알 수 없는 인자이고 기동 실패(종료 코드 2)다 |
| `raw` | 지운다. 치면 알 수 없는 명령으로 `WARN` 한 줄이다 |
| `rx.raw` | 지운다. 송신 측 짝이 없어지면 대조할 상대가 없다 |
| `hash` 모듈 | 남긴다. `wintun.dll` 해시 확인과 시험 빌드의 `data.tx`, `data.rx` 가 쓴다. `rx.raw` 만 쓰던 앞 16자 형식은 지운다 |
| `scripts/e2e-check.ps1` | 남기고 줄인다. 두 프로세스의 기동과 bind, `counters`, 알 수 없는 명령, `quit` 의 종료 코드를 본다 |

바이트 단위 일치는 Phase 4~5 검증의 `DATA` 왕복 일치(`data.tx`, `data.rx`)가 본다. 송신 실패가 `tx_err_send` 를 올리고
`socket.error` 줄에 오류 코드를 남기며, 그 뒤에도 루프가 콘솔 명령을 처리하는 것은 `tests/loop_test.cpp` 의 송신 실패 시험이 본다.

## 대안

**마지막 정리 Phase 까지 남기기.** 버렸다. Phase 7 부터 `rx.raw` 가 게임 트래픽마다 줄을 낸다. `rx.raw` 만 먼저 지우면
`raw` 의 송수신 대조가 성립하지 않아 남긴 둘이 쓸모가 없다.

**시험 빌드에만 남기기.** 버렸다. Phase 1 의 송수신 확인은 끝났고, 같은 성질을 `DATA` 왕복 일치가 본다. 남기면 시험 빌드에만
있는 기동 인자와 그것을 거르는 시험이 계속 따라온다.

**`scripts/e2e-check.ps1` 을 지우고 남는 검사를 다른 스크립트로 옮기기.** 버렸다. 남는 검사는 제어 서버 없이 도는 것들이라
DynamoDB local 을 요구하는 `scripts/lobby-check.ps1` 에 넣으면 실행 조건이 무거워진다.

## 결과

**얻는 것.**

- 실제 트래픽에서 데이터그램마다 로그 줄이 나가지 않는다
- 사용자가 준 주소로 임의의 바이트열을 보내는 경로가 없다. `--stun` 으로 받은 주소에는 STUN Binding Request 만 나간다
- 기동 인자와 콘솔 명령이 각각 하나씩 줄어든다

**치르는 것.**

- 한 기기에서 관리자 권한 없이 두 프로세스 사이의 바이트 일치를 보는 끝에서 끝까지 시험이 없다. `DATA` 왕복 일치는 세션이
  있어야 하므로 제어 서버가 필요하다
- 송신 실패를 실행 파일 수준에서 보는 시험이 없다. 단위 시험이 같은 루프 코드로 본다
