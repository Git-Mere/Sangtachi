# 시연을 마치고 plan.md 를 고친다

## 왜 했나

시연(2026-11-05)이 끝났다. `plan.md` 는 시연과 `mere-galaxy` 정리를 아직 Phase 9 전의 일정으로 적고 있었다.

## 시연 결과

소유자의 보고다. 이 저장소의 도구로 잰 값이 아니다.

| 참가자 | 망 |
|--------|----|
| 소유자 | 학교 유선 LAN |
| `mere-galaxy`(호스트, Minecraft 서버) | 소유자의 집 Wi-Fi([ADR 0038](../../decisions/0038-시연-호스트를-집-wi-fi-에-둔다.md)) |
| 소유자의 누나 | 한국의 본인 집 Wi-Fi |
| 소유자의 친구 | 미국 워싱턴 |
| 시연 자리에 같이 있던 친구 | 기록하지 않았다 |

다섯이 한 방에서 Minecraft 를 했다. 소유자는 지연이 체감되지 않았다고 보고했다. RTT, 손실, 수립 시간은 재지 않았다.

## 결정

- **`/etc/sudoers.d/90-sangtachi` 를 지우지 않는다.** `mere-galaxy` 를 시험에 계속 쓰기 때문이다. 소유자 결정이다. 시험에서 뺄 때 지운다
- **Wi-Fi 절전, Minecraft 서버, Sangtachi 호스트는 따로 되돌리지 않는다.** 소유자가 재부팅해서 끈다. 재부팅하면 Wi-Fi 절전이 다시 켜지므로
  실측 전에 끄는 절차를 `plan.md` 에 남겼다
