# 0020. Phase 4 세션 구현 전의 문서 부채 여섯을 닫는다

- 상태: 채택
- 날짜: 2026-10-08
- 관련: [`../protocol.md`](../protocol.md) 5.6·8.5·9.1·9.4.1·10.1·11장, [`../concurrency.md`](../concurrency.md) 4·5·7·8장, [`../control_plane.md`](../control_plane.md) 3.3·3.5·4.4, [`../roadmap.md`](../roadmap.md) Phase 4·8, [ADR 0017](0017-로컬-후보-판정-기준.md), [ADR 0018](0018-받은-후보에서-자기-서브넷-브로드캐스트를-거부한다.md)

## 맥락

`plan.md` 문서 부채 가운데 여섯이 결정을 기다렸다. 앞의 셋은 Phase 4 세션 구현 전에 정해야 했다.
선택지와 장단점을 저장소 소유자에게 보였고 소유자가 추천안을 모두 골랐다.

## 결정

**1. `IDLE` 에는 세션 객체가 없다.** 상대 후보를 받으면 세션을 `PUNCHING` 으로 만든다. `peer_id` 를 먼저
알아도 그 전에는 만들지 않는다. `protocol.md` 9.1 상태가 갖는다.

**2. 종료 상태의 세션 객체는 2분 남긴 뒤 지운다.** 많아야 `MAX_PEERS - 1` 개이고 넘으면 가장 오래 남긴
것부터 지운다. 방을 떠나면 함께 지운다. 남긴 세션은 세션 상한에 들지 않는다. `protocol.md` 5.6 `CLOSE` 가
갖는다.

**3. 로컬 후보와 자기 서브넷 집합은 `[loop]` 가 만들고 쓴다.** 로비 상태 기계, STUN, 받은 후보의 위생이
이미 `[loop]` 에서 돈다(`client/include/sangtachi/control/runner.hpp`). 인터페이스 읽기는 이 기기에서
중앙값 2.1ms 였다. `concurrency.md` 5장 상태 소유가 갖는다.

**4. 후보 위생에 예약 `240.0.0.0/4` 와 "이 네트워크" `0.0.0.0/8` 을 더한다.** 서버와 클라이언트 둘 다다.
`protocol.md` 10.1 이 갖는다.

**5. 이름 안에 공백이나 탭이 있는 헤더 줄을 거부한다.** RFC 9110 5.1 의 이름은 토큰이다.
`control_plane.md` 3.3 이 갖는다.

**6. Phase 8 제목을 "Minecraft 검증과 GUI 시연" 으로 바꾼다.**

4 와 5 의 코드와 서버 배포는 Phase 4 의 표시 이름 배포에 묶는다(`roadmap.md` Phase 4).

## 대안

**1 의 대안.** `peer_id` 를 알면 `IDLE` 세션을 만든다. 버렸다. 일찍 온 `HELLO` 를 따로 셀 수 있지만 9.4.1 과
8.1 을 다시 쓰고 카운터를 더해야 한다. 그 `HELLO` 는 200ms 마다 다시 온다. `IDLE` 에서 받은 `HELLO` 의 출발지를
후보로 쓰는 안(ICE 의 peer-reflexive)은 v1 범위 밖이다.

**2 의 대안.** 방을 떠날 때까지 남긴다. 버렸다. 호스트가 방을 오래 열면 쌓인다. 즉시 지운다. 버렸다. 5.6,
9.4.1, 로드맵 검증과 `drop_terminal_state` 를 고치거나 없애야 하고 종료 뒤 수신을 진단하는 자리가 사라진다.

**3 의 대안.** `[control]` 이 읽어 넘긴다. 버렸다. 새 요청 종류가 생기고 `[control]` 이 상태를 갖지 않는다는
규칙이 깨진다. 멈춤은 가장 짧은 타이머보다 두 자릿수 작다.

**4 의 대안.** 그대로 둔다. 버렸다. 의미 없는 목적지로 `HELLO` 가 나간다. 허용 목록으로 바꾼다. 버렸다.
목록을 잘못 잡으면 정상 후보를 잃고, 그 근거를 아직 모은 적이 없다.

**5 의 대안.** 표 밖 헤더로 무시한다. 버렸다. 이미 거부하는 "이름과 콜론 사이 공백" 과 같은 문법 위반을
다르게 다루게 된다.

**6 의 대안.** 그대로 둔다. 버렸다. 제목과 목표가 어긋난다.

## 결과

**얻는 것.**

- Phase 4 세션 구현을 막던 문서 사이의 모순이 없어진다
- 문서 부채가 다섯으로 준다

**치르는 것.**

- 4 와 5 는 문서가 코드보다 앞선다. 서버와 클라이언트가 고쳐지기 전까지 배포된 서버는 두 대역을 저장하고
  이름 안의 공백을 무시한다. `roadmap.md` Phase 4 가 그 작업을 갖는다
- 남긴 종료 상태 세션마다 만료 하나가 는다
