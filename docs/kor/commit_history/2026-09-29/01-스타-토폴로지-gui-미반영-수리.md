# 스타 토폴로지와 GUI 결정의 미반영 자리 수리

- Phase: 문서
- 관련: [ADR 0006](../../decisions/0006-무중계-스타-토폴로지.md), [ADR 0007](../../decisions/0007-gui-핵심-범위-qt.md), [ADR 0008](../../decisions/0008-스타-토폴로지-후속-결정.md), [ADR 0009](../../decisions/0009-방-호스트-임대.md)

## 왜

앞 커밋 셋(`5795eac`, `f832e34`, `bdb30f0`)이 한 방 5인 무중계 스타와 최소 GUI 를 반영했다.
그 결과를 렌즈 셋으로 감사했더니 blocker 14건이 남아 있었다. `docgate.py` 는 그때도
`VERDICT: pass` 였다. 게이트는 미러 짝, 헤딩, 표·링크 수를 세고 **문서가 자기 자신과
모순되는지는 보지 않는다.** 이 커밋은 그 14건을 닫는다.

영어 미러는 누락이 없었다. 3커밋의 한국어 변경이 전부 미러에 있었고(`MAX_PEERS` 11/11,
`ROSTER` 12/12, `Qt` 8/8, ADR 링크 10/10), 그래서 14건은 전부 **원본 결함**이었다. 미러는
같은 모양으로 틀려 있었다.

### 판정 기준과 미집행 의무

- `roadmap.md` Phase 3 검증의 `다른 nonce 로 부르면 room_full` 은 **정상 구현이 통과할 수
  없는 기준이었다.** 5인 방에서 다른 `client_nonce` 는 새 참가이고 `room_full` 은 풀이 다 찬
  뒤다. 재발 방지 규칙 3 이 겨냥한 자리다
- ADR 이 `roadmap.md` 에 걸라고 한 측정 넷을 걸었다. 호스트의 4쌍 동시 펀치와 호스트 NAT
  경고 여부(Phase 4 착수 전), `CLOSE` 최대 4개와 어댑터 정리의 3초 유예(Phase 8), 5인 동시
  참가의 경합(Phase 3 검증)
- **호스트 NAT 경고는 ADR 0006 이 남긴 미결 가운데 어디에도 걸리지 않은 하나였다.** ADR 0006
  의 미결 불릿은 여덟인데 ADR 0008 이 그것을 일곱으로 세고 여섯을 닫았다. 빠진 하나가 이것이다.
  ADR 0008 이 스스로 내리는 결정은 아홉이고 그 수와는 관계가 없다

## 어떻게 했나

감사와 수리를 모두 하위 에이전트로 나눴다. 감사는 렌즈 셋(5인 축, GUI 축, 안내·미러 축),
수리는 파일 소유로 넷으로 갈라 한 파일을 두 에이전트가 만지지 않게 했다. 수리 프롬프트에는
`docs/kor` 만 고칠 것, 기록 폴더를 건드리지 말 것, 값을 지어내지 말 것을 공통으로 넣었다.

**지어내지 않고 남긴 것이 둘 있다.** `protocol.md` 9.4.1 의 `IDLE` 전제와 9.1 의 `IDLE`
정의가 갈리는 구간, 그리고 호스트 NAT 경고의 판정 입력이다. 둘 다 어느 문서도 정하지 않았고
빈자리를 메우려고 단정하지 않았다. 앞의 것은 `plan.md` 문서 부채에, 뒤의 것은 `roadmap.md`
Phase 4 착수 전에 있다.

- `python tools/docgate/docgate.py` -> `link` 종류 0 건. `parity` 4 건은 영어 미러를 아직
  만들지 않아서 나는 것이고 `CLAUDE.md` 가 정상으로 정한 상태다
- 낡은 문구 전수 확인. `한 방에 2 피어`, `초기는 2 피어`, `세션은 하나`, `상대 피어 ID`,
  `상대 피어의 가상 IP`, `다른 nonce 로 부르면` 이 한국어 문서에서 0 건이다
- `roadmap.md` 의 `ROSTER` 가 0 건에서 5 건, `windows-prereq.md` 의 `Qt` 가 0 건에서 7 건
- `protocol.md` 11장 타이머 표의 종류를 세어 `concurrency.md` 4장의 새 근거 문장이 참인지

- 개수 주장 대조. `plan.md` 문서 부채 8 건과 표 행 8 개, ADR 9 건과 파일 9 개

## 스크래치 정리에서 나온 다섯

상위 폴더의 작업 파일(`star-followup-*.md`, `sangtachi-scratch/`)을 지우기 전에 레포에 안
들어간 것이 있는지 전수로 봤다. 소유자 결정 누락과 ADR 에 없는 버린 대안은 없었고, **시점이
어디에도 안 걸린 미결 다섯**이 나왔다. 지우기 전에 옮겼다.

| 무엇 | 어디에 |
|------|--------|
| 라우팅 표의 소유자. `protocol.md` 8.5 가 `concurrency.md` 5장을 가리키는데 그 목록에 항목이 없었다 | `concurrency.md` 5장 상태 소유 |
| 링 256 의 근거가 단일 세션 전제였다. 세션마다 붙는 주기를 세션 수 상한으로 다시 적었다 | `concurrency.md` 6장 |
| `send <n> [size]` 계약에 목적지가 없다. 세션이 여럿이면 어느 세션인지 정해지지 않는다 | `roadmap.md` Phase 4 시험 장치 |
| GUI 조작과 제어 평면 속도 제한의 관계. `control_plane.md` 6.4 는 GUI 를 다루지 않는다 | `roadmap.md` Phase 8 착수 전 |
| GUI 에서의 권한 승격과 잔존물 정리 시점 | `roadmap.md` Phase 8 착수 전 |

작업 파일에는 실측 원본이 없었다. 공인 IP, 자격 증명, 인스턴스 주소가 한 건도 없어 그대로
지웠다.

## 크로스 모델 리뷰

Codex 로 렌즈를 바꿔 가며 돌렸다. 전체 diff 에 시나리오 추적과 자기모순, 그다음 `plan.md` 와
이 기록을 포함한 전체 diff 에 지움과 개수, 이 기록의 증분에 기록, 스크래치에서 옮긴 다섯에
유도와 의무를 걸었다. 마지막 라운드가 `LGTM` 이다. 기각한 지적은 그다음 라운드 프롬프트에
적어 같은 지적이 다시 올라오지 않게 했다. 한 호출에 렌즈를 셋 이상 넣지 않았다.

| 지적 | 판정 |
|------|------|
| `roadmap.md` Phase 8 검증. 끊는 대상이 호스트면 명부를 보낼 쪽이 없어 그 기준이 성립하지 않는다 | **반영.** 기준을 플레이어 이탈로 한정하고 호스트 종료는 로비 복귀를 보는 것으로 따로 적었다 |
| `plan.md`. GUI 는 Phase 8 구현 전인데 "코드에 반영됐다" 가 과장이다 | **반영.** 코드 쪽은 `--rejoin` 제거만이고 나머지는 해당 Phase 의 몫이라고 적었다 |
| `commit_history/` 에 파일을 더한 것이 "기록은 고치지 않는다" 를 어겼다 | **기각.** 그 규칙은 **이미 있는 기록을 고치지 말라는 것**이고, `CLAUDE.md` 는 의미 있는 커밋마다 새 기록을 남기라고 정한다. 리뷰어가 레포 규칙을 반대로 읽었다 |
| 기록의 `관련` 목록에 ADR 0009 가 빠졌다 | **반영.** 이 기록의 `관련` 목록에 ADR 0009 를 더했다. 이번 변경이 `CLAUDE.md` 에 그 결정도 함께 적었기 때문이다 |
| `CLAUDE.md` 의 "후속 결정 아홉" 과 기록의 "일곱 중 여섯" 이 충돌한다 | **기각.** 다른 수를 센 것이다. 아홉은 ADR 0008 이 내리는 결정의 수이고, 일곱과 여섯은 ADR 0008 이 ADR 0006 의 미결을 센 수다. 다만 그렇게 읽힐 수 있어 기록의 그 문장을 풀어 적었다 |
