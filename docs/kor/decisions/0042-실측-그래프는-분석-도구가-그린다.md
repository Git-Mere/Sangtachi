# 0042. 실측 그래프는 분석 도구가 그린다

- 상태: 채택
- 날짜: 2026-11-23
- 관련: [ADR 0039](0039-phase-9-착수-전-결정.md) 집계와 그래프, [`../spec.md`](../spec.md) NFR-5, [`../roadmap.md`](../roadmap.md) Phase 9 실험 결과 시각화

## 맥락

ADR 0039 는 집계와 그래프를 CloudWatch 로 정했다. 서비스가 커스텀 지표를 넣고 소유자가 대시보드에서 본다. 그래프 라이브러리를 서비스에 넣는 안은 NFR-5 의 교수 승인과 t3.micro 의 자원 때문에 버렸다.

`experiments.md` 에 실을 그래프를 만들 때 대시보드로는 두 가지가 안 됐다.

- 대시보드의 가로축은 시각이다. ADR 0001 따라야 할 조치 2번은 시각을 날짜까지만 공개한다. 화면을 캡처하면 시각을 지워야 한다
- 지표에는 차원이 없다. 환경을 가르는 것은 로컬 묶음 파일의 시간 범위뿐이라 대시보드가 환경별로 나눠 그리지 못한다. 성공률의 Wilson 구간도 내지 않는다

## 결정

**`experiments.md` 의 그래프는 `tools/tm-plot` 이 그린다.**

| 자리 | 정한 것 |
|------|---------|
| 시간에 따른 값 | CloudWatch 1분 해상도 지표를 `get-metric-statistics` 로 받아 그린다. 가로축은 묶음 안 경과 시간이다 |
| 분포와 성공률 | 분석 스크립트(`tools/tm-analysis`)가 읽는 레코드와 그 계산 함수로 그린다. 표의 숫자와 같은 값이다 |
| 라이브러리 | matplotlib. 시험·분석 전용 의존성으로 저장소 소유자가 승인했다(NFR-5) |
| 실행 환경 | `uv run --with matplotlib` 의 임시 환경. 제어 서버와 텔레메트리 서비스의 의존성 목록에 넣지 않는다 |
| 그림 파일 | `docs/assets/phase9/`. 한국어와 영어 문서가 같은 파일을 쓴다 |

ADR 0039 의 나머지는 그대로다. 서비스는 CloudWatch 에 지표를 넣고, 대시보드는 소유자가 보는 자리로 남는다.

## 대안

| 안 | 내용 | 기각 사유 |
|----|------|-----------|
| A | 대시보드 화면을 캡처하고 시각을 지운다 | 환경별로 나눠 그리지 못하고 Wilson 구간이 없다. 캡처는 다시 만들 수 없다 |
| B | 표준 라이브러리로 SVG 를 직접 쓴다 | 의존성 승인은 필요 없지만 그래프 코드를 직접 유지한다. 저장소 소유자가 matplotlib 을 골랐다 |
| C | 그래프 없이 표만 싣는다 | `roadmap.md` Phase 9 작업이 실험 결과 시각화를 요구한다 |

## 결과

**얻는 것.** 환경별 그래프를 같은 자료에서 다시 만들 수 있다. 시각이 그림에 들어가지 않는다.

**받아들이는 한계.**

- NFR-5 의 시험 전용 의존성을 시험·분석 전용 의존성으로 넓힌다. [ADR 0005](0005-시험-프레임워크-catch2.md) 에서 교수가 받아들인 것은 시험 실행기의 구분이다. 분석 도구를 같은 종류에 넣는 것은 저장소 소유자의 판단이다
- 시간에 따른 그래프는 CloudWatch 의 1분 해상도가 남는 15일 안에 값을 받아야 다시 그릴 수 있다
- 그림 파일은 레포에 이진 파일로 남는다. 자료가 바뀌면 다시 그려 같이 커밋한다
