# 실측 결과 반영: field-test 폴더와 ADR 0024

## 왜 했나

2026-10-14 에 `tools/field-test` 시험 1(서로 다른 두 집)과 시험 2(같은 공유기)를 돌렸다. 결과를 확인하면서 세 가지가 나왔다.

- 실측 자료가 `tools/nat-probe/results`, `records`, `tools/nat-lifetime/results`, 사용자 폴더에 흩어져 있었다. 저장소 소유자가
  실측을 한 폴더에서, 날짜별로, 같은 양식의 보고서로 남기자고 했다
- `plan.md` 의 결정 대기 둘(호스트 NAT 경고, 실측에서 본 문서대로의 거동 둘)을 저장소 소유자가 정했다
- 재측정이 끝나 `plan.md` 의 문단 하나가 낡았다

## 실측 결과 (시험 1, 2)

자세한 것은 로컬 보고서 `field-test/2026-10-14/` 에 있다.

| 항목 | 결과 |
|------|------|
| nat-probe 호스트 네 쌍 | 3회 연속 모두 성공. 두 집 모두 endpoint-independent. ADR 0001 판정은 유지된다 |
| 서로 다른 두 집 연결, M-2, M-3, M-6 | 통과 |
| D1 AWS 미경유 | 통과 (A 캡처에 서버와의 UDP 0개) |
| D2 출발지 포트 | 포트 하나는 통과. 프로세스의 UDP 포트 확인 파일이 없어 그 부분은 판정 못 함 |
| D3 같은 LAN | 통과. 서로의 사설 후보를 학습했다 |
| 로비 체류 | 판정 못 함. 체류가 3분이 아니라 약 50~70초였다 |

## 중요한 결정

- 같은 `generation` 을 "조용히 버리는" 안을 처음 제시했으나 8장의 "폐기마다 전용 카운터" 와 어긋나 "받아들이되 바꾸는 것이 없다" 로 했다. 결정은 ADR 0024 다
- 실측 보고서는 커밋하지 않는다. 공개 레포에 두 집의 실측 시각과 기록을 올리지 않는 ADR 0001 의 방침을 그대로 따른다
